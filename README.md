基于 pnpm workspace 的 Next.js 后台管理系统模板，纯前端架构，开箱即用。

## 快速开始

```bash
pnpm install && pnpm dev
```

访问 http://localhost:3000

## 项目结构

```
├── apps/basic-admin/      # 示例后台（用户管理、系统设置）
└── packages/
    ├── uikit/             # UI 组件库
    ├── shared/            # 工具函数
    ├── constants/         # 常量定义
    └── types/             # 类型定义
```
